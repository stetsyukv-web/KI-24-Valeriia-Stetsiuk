# Лабораторна робота №1: Змінні, оператори, умови, цикли

**Мета:** закріпити практичні навички роботи зі змінними, операторами, умовними конструкціями та циклами в JavaScript.

## Файли лабораторної роботи

* `index.html` — підключає JavaScript-файли та дозволяє запустити код у браузері.
* `run.js` — викликає функції з `lab1.js` та виводить результати їх виконання в консоль браузера.
* `lab1.js` — містить функції, які потрібно реалізувати відповідно до умов завдань.

## Завантаження файлів

Ви можете завантажити цей репозиторій як `.zip`-архів, розпакувати його та скопіювати потрібні файли у папку з вашим локальним репозиторієм.

> **Увага:** не копіюйте папку `.git` із завантаженого архіву. У вашому локальному репозиторії вже є своя папка `.git`, яка використовується Git для зберігання історії змін та інформації про репозиторій.

## Запуск коду

Для запуску лабораторної роботи відкрийте файл `index.html` у веббраузері, наприклад Chrome або Edge.

Після цього:

1. Відкрийте **DevTools** (`F12`).
2. Перейдіть на вкладку **Console**.
3. У консолі ви побачите результати виконання JavaScript-коду.

Файл `index.html` підключає `run.js` і `lab1.js` за допомогою тегів `<script>`.

## Завдання

Файл `lab1.js` містить **9 завдань**. У більшості з них потрібно дописати код функції відповідно до її опису та перевірити правильність роботи.

Основні зміни потрібно виконувати у файлі:

`lab1.js`

Файл `run.js` містить код для виклику та перевірки функцій із `lab1.js`.

Модифікувати `run.js` для виконання лабораторної роботи **не потрібно**, але за необхідності це не забороняється.

### Важливо

Не змінюйте:

* назви функцій;
* кількість і порядок параметрів функцій;
* назви файлів.

Змінювати потрібно лише реалізацію функцій у `lab1.js`, якщо в умові конкретного завдання не зазначено інше.

Це необхідно для того, щоб код із `run.js` міг коректно викликати та перевіряти ваші функції.
